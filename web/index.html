Подключить реальные цены

Сайт читает снимки Blizzard, которые собирает GitHub Actions. Ключи Battle.net остаются в GitHub Secrets и не попадают в браузер.

  1. Создайте API-клиент на Battle.net Developer Portal ↗.
  2. Загрузите исходники в публичный репозиторий GitHub. В Secrets добавьте BNET_CLIENT_ID и BNET_CLIENT_SECRET.
  3. В Settings → Pages выберите GitHub Actions и запустите workflow «Collect & publish». Сборщик обнаружит доступные рулсеты и аукционы.
EU, US, KR и TW. Китай использует отдельную платформу и здесь не подключён. История начнёт накапливаться с первого успешного запуска. Расписание GitHub может запускаться с задержкой.

Оставьте пустым, чтобы использовать данные этого сайта. Сторонний источник должен разрешать CORS. Ключи сюда вводить не нужно.
